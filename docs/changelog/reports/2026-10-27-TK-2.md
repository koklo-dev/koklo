# Period report — 2026-10-27 (TK-2, script check:size et dérogations)

## Summary
Adds the `check:size` gate (CDC §17.2): 300 lines max per source file, 500 per test
file, with time-limited waivers read from `.koklo/waivers.yaml`. It runs as part of
`pnpm lint`.

## Architecture and Runtime
New files in `packages/config`: `src/check-size.ts`, `src/waivers.ts`, `README.md`;
new `.koklo/waivers.yaml` (initially `waivers: []`). New dependency `yaml` 2.9.1 in
`packages/config` (lockfile updated). `packages/config` `lint` is now
`biome ci --config-path=../.. . && pnpm check:size`; the root gains a `check:size`
script. See [architecture.md](../../architecture.md#file-size-gate-checksize-tk-2).

## Domain Model Changes
None.

## API and Tests
No API. New tests in `packages/config/test/check-size.test.ts`.
Gate results for this change: not recorded in this report (TO DOCUMENT).

## Quality Gates and Fixes
`pnpm lint` now fails on any source file over 300 lines or test file over 500 lines,
unless a non-expired waiver exists; an expired waiver fails with the file name, expiry
date and author. See
[quality-and-operations.md](../../quality-and-operations.md#lint-types-and-build-workspace).

## Functional Impact
None.

## Risks and Follow-ups
- The check scans the whole repository from the root; new generated-code folders other
  than `generated/` and `migrations/` need a `@generated` / `DO NOT EDIT` header or a
  `*.generated.*` name to be skipped.
- ADR recommended by the impact score (a new dependency and a new quality gate); none
  written in this pass (ADRs were not in the impacted documents).
