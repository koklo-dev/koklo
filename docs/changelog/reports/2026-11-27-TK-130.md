# Rapport : TK-130, retrait de l'exécution d'agents par Koklo (2026-11-27)

## Résumé
Koklo n'exécute plus aucun agent de code (décision du 06/11/2026, `docs/refonte/passations/17-decisions-2026-11-06-agents-locaux.md` §1). Le port d'exécution, son adaptateur et les quotas du fournisseur sont supprimés de `packages/delivery` ; la machine d'étapes pure est gardée pour `ticket.progress`. ADR 0023 accepté, ADR 0014 « remplacée ».

## Architecture et exécution
Recherche de dépendances faite avant la suppression (`git grep`) :
- aucune application ni aucun paquet ne dépendait de `@koklo/delivery` ; aucune mention dans Makefile, Dockerfile, `.deploy` ni `biome.json` ; dans `.github`, seuls les scripts de couverture et un commentaire de `ci.yml` citent le paquet ;
- hors du paquet, `packages/delivery` n'est lu que par la couverture, par `apps/api/test/ai-engine-wiring.test.ts` (plus de 10 sources exigées, 13 restent) et par une garde de `packages/config` (chemin fictif) ;
- aucun fichier gardé n'importait un fichier supprimé, `@koklo/*` ou `node:*` ;
- les scripts qui lancent un processus (`e2e/scripts`, `packages/db`, `packages/github/scripts`) ont été lus : aucun ne lance un agent ;
- les motifs d'invocation d'agent ne restaient, hors paquet, que dans `.project/loop/claude-invoke.sh` (boucle de développement, hors périmètre, non touchée) ; la copie historique `apps/api/test/fixtures/sprints/sprint-014.md` cite encore l'ancien code.

Fichiers retirés (sous `packages/delivery/`) :
- 38 sources : `src/claude-code/` (11), `src/agent-*.ts` (7), `src/testing/` (6), `src/quota-*.ts` (14) ;
- 28 fichiers de test, d'aide et de fixture liés à ce code.

Fichiers gardés : 13 sources (`run*.ts`, `block-cause`, `errors`, `one-of`, `value-check`, `index`), les 12 `run-*.test.ts` et `test/helpers.ts`, non modifiés.

Fichiers modifiés : `src/index.ts`, `src/errors.ts` (`InvalidQuotaError` et `StaleQuotaError` retirées), un commentaire dans `src/run-effects.ts` et `src/run-resume.ts`, `package.json` (plus de dépendance d'exécution, export `.` seul), `pnpm-lock.yaml` (7 lignes retirées), les tests `purity` et `incident-25-agent-runtime-boundary` avec leur scan.

## Modèle de domaine
États, transitions, effets et causes de blocage inchangés ; `quota_hit` reste un événement neutre. Les types du port d'agent et des quotas n'existent plus.

## API et tests
Aucun contrat, procédure, schéma ni migration touché. L'API publique de `@koklo/delivery` se réduit aux 18 exports de la machine.

Tests réellement lancés (fichiers nommés, en local) :
- `packages/delivery`, 14 fichiers avec couverture : 550 tests réussis ; instructions, branches, fonctions et lignes à 100 % ;
- `apps/api/test/ai-engine-wiring.test.ts` : 13 réussis ;
- `packages/config/test/llm-testing-import-guard.test.ts` : 33 réussis ;
- après la documentation, les contrôles qui la lisent : `packages/schema/test/domain-links.test.ts` (29 réussis) et `.github/scripts/deploy-workflow.test.sh` (52 réussis).

## Qualité et corrections
- `pnpm --filter @koklo/delivery typecheck` : sans erreur.
- `pnpm lint` (Biome, `turbo boundaries`, imports profonds) : vert.
- La garde `incident-25` est durcie : plus d'adaptateur autorisé, `node:child_process` limité à deux aides de test de `packages/db`, aucune dépendance `@anthropic-ai/claude-*`.
- Documentation : ADR 0023 et 0014, `architecture.md`, `domain-model.md`, `quality-and-operations.md`, `refonte/ecarts.md` ; contrôles par `grep` et vérification des ancres.

## Effet fonctionnel
Aucun : pas d'écran, pas de procédure, aucun guide fonctionnel à modifier. Rien à déployer de particulier.

## Risques et suites
- Non vérifié en local : suites complètes, couverture agrégée, build, e2e, audit des dépendances (Trivy), `pnpm install --frozen-lockfile` à froid. La CI conclut.
- La garde par motifs est un filet, pas une preuve.
- La machine d'étapes n'a pas encore d'appelant ; son adéquation aux étapes de la maquette 23 sera jugée au lot 12c (B839).
- MCP et CLI `koklo` à construire (TK-63 à TK-65, TK-69, TK-131) ; titulaire « runner » retiré par TK-131.
- Antérieur au ticket, non corrigé : quatre liens vers des ancres absentes (`onboarding.md`, rapports TK-2, TK-19 et TK-21) ; l'index des ADR d'`architecture.md` omet les 0012, 0013 et 0017 à 0022.
