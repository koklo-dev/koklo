# Period report — 2026-10-27 (TK-12, worker pg-boss et job noop)

## Summary
New package `apps/worker` (`@koklo/worker`): a separate process that starts pg-boss on
the shared PostgreSQL database and consumes a `noop` job.

## Architecture and Runtime
`DATABASE_URL` is required at startup. The process stops cleanly on `SIGINT`/`SIGTERM`.
`pnpm-lock.yaml` updated for `pg-boss` 12.38.0 and `@testcontainers/postgresql` 12.2.1.
See [architecture.md](../../architecture.md#worker-pg-boss-and-noop-job-tk-12).

## Domain Model Changes
None.

## API and Tests
No API change. Integration test: a published `noop` job is consumed and reaches the
`completed` state (`apps/worker/test/noop.integration.test.ts`, needs Docker). See
[quality-and-operations.md](../../quality-and-operations.md).

## Quality Gates and Fixes
Package exposes `lint`, `typecheck`, `test`, `build`, `start` and `dev`.

## Functional Impact
None for end users: no screen. No functional guide or screenshot written.

## Risks and Follow-ups
- The impact score recommended an ADR (pg-boss as job runner, separate process); it is
  outside this pass's `impacted_docs`, so it is not written.
- Retry, scheduling, queue policies and observability of jobs are not defined yet.
