# Period report — 2026-10-27 (TK-9, contrat oRPC v2 et OpenAPI)

## Summary
New package `@koklo/contract`: oRPC v2 contract (`health`, `project.list`) with typed
errors, an OpenAPI 3.1.0 generator, and a test guard that fails when the generated
OpenAPI changes without a version change.

## Architecture and Runtime
`packages/contract` added (tag `contract`), with `pnpm-lock.yaml` updated for
`@orpc/contract`, `@orpc/openapi`, `@orpc/zod` (`2.0.0-beta.46`) and `zod` 4.6.7. See
[architecture.md](../../architecture.md#api-contract-package-tk-9).

## Domain Model Changes
None.

## API and Tests
`GET /health` and `GET /projects`, errors `INTERNAL` (500, `requestId`), `UNAUTHORIZED`
(401), `FORBIDDEN` (403). Reference files `openapi/openapi.json` and
`openapi/versions.json`; tests CT-2 to CT-9 in `packages/contract/test/contract.test.ts`.
See [api-contract.md](../../api-contract.md).

## Quality Gates and Fixes
Package exposes `lint`, `typecheck`, `test`, `build` and `openapi:generate`. See
[quality-and-operations.md](../../quality-and-operations.md).

## Functional Impact
None for end users: no screen. No functional guide or screenshot written.

## Risks and Follow-ups
- oRPC is on a v2 beta (the only line with `.meta(openapi(...))`); move to 2.0 stable.
- The impact score recommended an ADR (contract-first with oRPC v2 beta); it is outside
  this pass's `impacted_docs`, so it is not written.
- Authorization enforcement and pagination are not defined yet.
