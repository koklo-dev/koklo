# Period report — 2026-10-27 (TK-85, blocs shadcn sidebar-07 et login-05)

## Summary
The hand-made app shell and login page are replaced by the shadcn blocks `sidebar-07` and
`login-05`, adapted to the `DESIGN.md` tokens and to the project `Icon` component. The sidebar is
collapsible to icons and becomes a `Sheet` under 768 px. Only GitHub remains as login provider.

## Architecture and Runtime
Shared components in `@koklo/ui`, blocks in `apps/web` (`app-shell.tsx`, `login-card.tsx`).
`--sidebar-*` variables map onto existing tokens (no new token). The block's `sidebar_state`
cookie stores the collapsed state (no personal data; to cite in the future privacy policy).
Production code is not part of the diff analysed for this pass: see the screen sheets.

## Domain Model Changes
None.

## API and Tests
