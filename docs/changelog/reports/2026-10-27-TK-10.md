# Period report — 2026-10-27 (TK-10, apps/api NestJS + oRPC)

## Summary
Adds `apps/api` (NestJS on Express + `@orpc/nest`) implementing the `@koklo/contract`
contract: `GET /health`, `GET /projects` (`project.list`) and `GET /openapi.json`.

## Architecture and Runtime
New app `apps/api` (tag `api`): validated configuration, `database`, `health` and
`project` modules (thin controller, service, `ProjectRepository` port, Prisma adapter).
`@koklo/db` now declares `exports` (`.` and `./testing`) and exposes `createDbClient`.
See [architecture.md](../../architecture.md) and
[ADR 0002](../../adr/0002-project-port-in-api.md).

## Domain Model Changes
None. The `key` field is removed from the contract's project schema (the model never
had one).

## API and Tests
Contract 0.2.0 (breaking: `key` removed from `project.list` items), OpenAPI and
`versions.json` regenerated. Integration tests on an ephemeral Postgres (`project.list`
returns the seed projects, tenant isolation, `/health` 200 / 500). See
[api-contract.md](../../api-contract.md) and
[quality-and-operations.md](../../quality-and-operations.md).

## Quality Gates and Fixes
`@nestjs/*` pinned to 12.2.0 (12.3.0 was published the same day and refused by the
release-age policy); `multer` overridden to 2.5.0 (GHSA-q7qp-rjg7-q26m).

## Functional Impact
None yet: `project.list` answers 401 until TK-11 provides the session-based
organization context.

## Risks and Follow-ups
- TK-11 supplies the real `OrganizationContext` and the 401/403 enforcement.
- The Prisma tenant-filter extension (CDC §18.4) is not planned in any ticket yet.
