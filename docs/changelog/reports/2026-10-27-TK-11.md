# Period report — 2026-10-27 (TK-11, GitHub sign-in and session guard)

## Summary
`project.list` now requires a session. Better Auth (GitHub OAuth, Prisma adapter) is mounted on
`/api/auth/*`; a per-procedure `SessionGuard` answers the typed `UNAUTHORIZED` (401) without one.

## Architecture and Runtime
New `apps/api/src/auth/` module, `SessionOrganizationContext` replaces `DenyOrganizationContext`,
`ERROR_STATUS_MAP` is shared by `ORPCModule` and `OrpcErrorFilter`. See
[architecture.md](../../architecture.md) and [ADR 0003](../../adr/0003-better-auth-session-guard.md).

## Domain Model Changes
None in this diff. The resolver reads the Better Auth `member` table through Prisma.

## API and Tests
No contract change. `auth-session.test.ts` and `auth-oauth.test.ts` added. See
[api-contract.md](../../api-contract.md).

## Quality Gates and Fixes
New dependency `better-auth` 1.7.14 (`pnpm-lock.yaml`, `pnpm-workspace.yaml` updated).
New required variables: `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL`, `GITHUB_CLIENT_ID`,
`GITHUB_CLIENT_SECRET`; the API no longer starts without them.

## Functional Impact
None documented yet (no screen).

## Risks and Follow-ups
- The test session only exists with `APP_ENV=test`; deployments must never use that value.
- `FORBIDDEN` is still not emitted; the Prisma tenant-filter extension (CDC §18.4) is still unplanned.
