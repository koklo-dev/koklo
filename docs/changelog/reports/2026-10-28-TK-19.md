# Report: TK-19 observability (2026-10-28)

## Summary
New shared package `@koklo/observability` (pino JSON logs, optional Sentry-compatible SDK for
GlitchTip). Api and worker log JSON to stdout with `requestId` / `jobId`; unexpected errors are
captured with those ids.

## Architecture and Runtime
`nestjs-pino` in the api, `instrumentJob` in the worker. See
[architecture.md](../../architecture.md#observability-koklo-observability-tk-19).

## Quality Gates and Fixes
`LOG_LEVEL` and `SENTRY_DSN` documented in
[quality-and-operations.md](../../quality-and-operations.md#observability-tk-19).
Pinned: pino 10.4.0, pino-http 11.0.0, nestjs-pino 5.3.1, @sentry/node 11.10.0.

## Risks and Follow-ups
- `guard` runs outside dependency injection: one logger per process.
- `@sentry/node` rather than `@sentry/nestjs` (explicit capture in `guard`).
