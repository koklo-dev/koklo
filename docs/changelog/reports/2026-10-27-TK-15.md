# Period report — 2026-10-27 (TK-15, e2e Playwright sur le vrai stack)

## Summary
New package `e2e/` (`@koklo/e2e`). `pnpm e2e` starts a throw-away Postgres, migrates, seeds, builds,
starts API and web, and runs Playwright; `pnpm dev` starts Postgres, web (:3000), API (:3001) and worker.

## Architecture and Runtime
Root `e2e` and `dev` scripts now call `node e2e/scripts/run.ts` / `dev.ts`. `apps/web` dev pins
`--port 3000`. `turbo.json` gains `globalPassThroughEnv` and `dev.passThroughEnv`.
See [architecture.md](../../architecture.md#real-stack-e2e-and-one-command-dev-tk-15) and
[ADR 0007](../../adr/0007-real-stack-e2e-orchestration.md).

## Domain Model Changes
None.

## API and Tests
No API change. Tests in `e2e/tests/projects.spec.ts`: a test session shows the seeded project list;
without a session `/projects` redirects to `/login`. `.github/scripts/detect-changes.sh` treats `e2e/*` as code.

## Quality Gates and Fixes
New CI job `e2e` (installs Chromium, runs `pnpm e2e`, uploads the Playwright report on failure).
See [quality-and-operations.md](../../quality-and-operations.md#real-stack-e2e-tk-15).
Result of the CI run: `pnpm e2e` in the `e2e` job (run 40532981037) → `2 passed`, including "session de test → liste des projets du seed" and "sans session, /projects redirige vers /login (vrai API)".

## Functional Impact
None for end users. No functional guide or screenshot written.

## Risks and Follow-ups
- Docker is required locally and in CI.
- `pnpm dev` needs `BETTER_AUTH_SECRET` and `GITHUB_CLIENT_*` in `apps/api/.env`.
