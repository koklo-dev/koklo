## Signalements (choix documentés qui contredisent la maquette)

- DESIGN.md §5.4 (ligne 288) dit l'entrée active de la navigation secondaire « sur `--surface` en 600 » ; la maquette (M:260) et le code (`bg-accent` = `--soft`) utilisent `--soft`. Le texte de DESIGN.md est à corriger, le code est juste sur le fond.
- B117 (projets en cases à cocher) et B118 (confirmation en ligne) : documentés, non comptés.
- B113 (trois chiffres) et B96 (sections Accès et règles, Agents, Journal absentes) : documentés, non comptés.

## Composants packages/ui à créer ou étendre

1. **`RolePill`** (ou variantes de `Badge`) : tonalités `soft` (propriétaire, administrateur), `outline` muted (développeur, designer, business), `amber` (client, jetons `--status-pending-*`) ; 24 px, `text-caption` ; icône facultative ; option interactive (`expand_more`).
2. **`Badge`** : taille `sm` (22 px, 11/600) et variante outline à texte `--muted-foreground`.
3. **`Avatar`** : taille 32 px, tonalités `soft` / `amber`, variante `tile` (carré rayon 14 sur `--primary`).
4. **`Table` variante `framed`** : bordure, rayon 12, en-tête `--surface` 12/500 muted.
5. **`SecondaryNav` / `NavItem`** : icône 18 px (pleine si courante), badge, groupe 11/600 capitales, actif `--soft` 600.
6. **`SegmentedControl`** (radios natives) pour le thème.
7. **`Switch` / `SwitchRow`** : déplacer depuis apps/web, 38 × 22 px, éteint `--border-strong`.
