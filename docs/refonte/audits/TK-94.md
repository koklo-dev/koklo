## Composants packages/ui à créer ou étendre

- `ListFooter` : état loading avec icône `progress_activity` primaire ; erreur avec texte muted et icône rouge ; icône 18 px.
- `VirtualList` : lignes squelettes de chargement (`loadingRows`) ; cadre rayon 12 intégré (`framed`).
- `Skeleton` : variante `row` (pavé d'identifiant + barre).
- `Pagination` : boutons 32 px bordés en mono, précédent/suivant `outline`, sélecteur de taille segmenté avec libellé « Lignes par page », sans `disabledReason`.
- `SegmentedControl` / `ToggleGroup` taille `xs` (24 px, actif `--secondary`).
- `Button` : taille `xs` (30 px).
- `EntityChip` variante `id` (pastille d'identifiant sans lien) ou `IdChip` ; `ListRow` (titre + sous-titre).
- `EmptyState` : variante `inline` (sans cadre ni tuile).
- `CountBar` : nom du total en gras ; tri avec icône après le texte ; libellé de résultat de recherche.
- `GroupSection` : variante `stacked`, rangée « Afficher N de plus » pleine largeur primaire, `actionIcon`, chevron 18, méta 12 px.
- `ZoneNode`, `DiagramMinimap` : dimensions de la planche (lot 6).
