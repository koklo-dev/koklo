# 0018 — Palette de commandes ⌘K : `cmdk` 1.1.1

- **Statut** : accepté le 2026-11-07 (TK-88, lot B ; la passation 01 §1.1 nomme déjà la bibliothèque)
- **Date** : 2026-11-07
- **Décideurs** : developer, designer (ticket TK-88)

## Contexte
La coquille de l'application ouvre une palette ⌘K : champ `combobox`, liste `listbox`, options navigables aux flèches, groupes, états de chargement, de vide et d'erreur. La recherche est faite par le serveur (questions.md B3) : la palette ne filtre rien localement.

## Options envisagées
| Option | Avantages | Inconvénients |
|--------|-----------|---------------|
| A. `cmdk` 1.1.1 | Sans style, donc aux jetons du produit ; rôles ARIA `combobox` / `listbox` / `option` ; `shouldFilter={false}` désactive le filtrage local ; navigation clavier, `Command.Dialog`, `Command.Loading`, groupes ; pairs React 18 et 19 ; licence MIT ; **aucune vulnérabilité connue** (OSV, vérifié le 2026-11-07) | Quatre dépendances `@radix-ui/*` (une copie de `react-dialog` en plus de celle de `radix-ui`) ; dernière publication en 2025 |
| B. `react-cmdk` | Palette prête à l'emploi | Style imposé, à contourner pour les jetons ; filtrage local par défaut ; écartée sur ces critères |
| C. `kbar` | Actions et raccourcis enregistrés globalement | Modèle d'actions inutile ici (résultats serveur) ; écartée sur ce critère |
| D. Palette maison | Aucune dépendance | Réécriture de la navigation clavier, de `aria-activedescendant` et du piège de focus ; coût de maintenance sans bénéfice |

## Décision
Option A, version exacte **1.1.1** (dernière version stable au 2026-11-07), ajoutée aux dépendances de `@koklo/ui` seulement (`pnpm --filter @koklo/ui add cmdk@1.1.1 --save-exact`).
- `cmdk` n'est importé que par `command-palette.tsx` ; aucune application ne l'importe. Un test le garde.
- `shouldFilter={false}` : les éléments viennent du serveur, jamais d'une liste chargée.

## Conséquences
- Une dépendance de production en plus, à suivre dans `dependency-audit` ; montée de version par Dependabot.
- Les tests jsdom ont besoin de `ResizeObserver` et de `scrollIntoView` (polyfills dans `test/setup.ts`).
- `cmdk` est la seule bibliothèque de palette autorisée : toute autre demande passe par un nouvel ADR.
