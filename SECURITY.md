# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.x     | yes       |

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Send an email to: security@koklo.dev

We respond within 48 hours and provide a patch within 7 days for critical issues.

## Scope

- Core application (this repo)
- API endpoints
- Data storage and encryption
- Agent execution sandbox
