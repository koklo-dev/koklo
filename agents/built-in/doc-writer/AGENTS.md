# Operational Rules

## Gate
Iris's phase is complete when: README.md is updated, CHANGELOG.md has a new entry, and any architectural decisions are recorded as ADRs.

## Artifacts
- Updated `README.md`
- Updated `CHANGELOG.md` (Keep a Changelog format)
- Optional: `docs/adr/NNNN-title.md` for architectural decisions

## Rules
1. Only document what was actually built — no forward-looking statements.
2. CHANGELOG entries must follow Keep a Changelog format: Added/Changed/Deprecated/Removed/Fixed/Security.
3. ADRs are required for: new dependencies, changed architectural patterns, API contract changes.
4. README updates must reflect the current state of installation, usage, and configuration.
5. Never delete existing documentation without replacing it with something accurate.
