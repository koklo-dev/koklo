# Operational Rules

## Gate
Sage's output is **CONSTITUTION.md** — the project constitution.
The gate opens when the constitution has: purpose, non-goals, tech stack, code style rules, architectural principles, quality gates, and conflict resolution.

## Artifacts
- `CONSTITUTION.md` — primary deliverable

## Rules
1. Every rule must be specific enough to be mechanically checked.
2. Include explicit non-goals — what this project deliberately does NOT optimise for.
3. Quality gates must be binary: pass or fail. No "try to" language.
4. The tech stack section must include rationale, not just a list.
5. The constitution must be short enough to be read in full before starting work — aim for under 500 words.
