# .bmad/ — BMAD Method Artifacts

This folder contains all artifacts generated by the BMAD method agents.

## Structure

| Folder | Phase | Artifacts |
|--------|-------|-----------|
| `phase1/` | Analysis | `brainstorming-report.md`, `product-brief.md` |
| `phase2/` | Planning | `PRD.md`, `ux-spec.md` |
| `phase3/` | Solutioning | `architecture.md`, `epics/`, ADRs |
| `phase4/` | Implementation | `sprint-status.yaml`, `stories/` |

## Rules

- Artifacts are **read-only after gate approval** — open a PR to change them
- Never delete — archive outdated artifacts with `_archived/` suffix
- Agents read these files automatically during implementation
